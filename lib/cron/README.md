# lib/cron/

Shared primitives for Kaya's cron job execution. There is no in-process
scheduler here — the daemon that used to own this directory (an in-process
job scheduler + control plane, plus its ProactiveEngine CLI tools) was
deleted outright in slice D1 (2026-07-03) because it wasn't running and its
one remaining job had no way to fire. See
`MEMORY/daemon/cron/jobs.retired/README.md` for the retirement record.

Scheduling now happens entirely via launchd + a jobs manifest:

- **Trigger**: a launchd plist per job under `~/Library/LaunchAgents`
  (`com.kaya.cron.<id>.plist`), generated by `bin/migrate-crons-to-launchd.ts`.
- **Manifest**: live job definitions live in `MEMORY/daemon/cron/manifests/`
  (see that directory's README); formally retired jobs live in
  `MEMORY/daemon/cron/jobs.retired/`.
- **Runner**: `bin/run-cron-job.ts <job-id>` is what every plist actually
  invokes. It reads the job's yaml, re-validates the schedule, and spawns the
  job.

## Files in this directory

| File | Purpose |
|------|---------|
| `JobSpec.ts` | Canonical Zod schema for a job definition (`JobSpecSchema`) |
| `JobSpawner.ts` | Shared spawn+timeout+classify primitive used by `run-cron-job.ts` |
| `RetryRunner.ts` / `RetryPolicy.ts` | Retry-on-failure loop and policy |
| `PowerState.ts` | Reads system power/sleep state to gate retries |
| `NetworkPrecondition.ts` | Checks network reachability before running a job |
| `FailureClassifier.ts` | Classifies a failed run (timeout, network, crash, ...) |
| `JobReconciler.ts` | Reconciles manifest state against installed launchd plists |
| `WakeLock.ts` | Prevents the Mac from sleeping mid-job |
| `RunLedger.ts` | Append-only log of job run outcomes, used for idempotency checks |

Each file's own header comment has the detailed design rationale. Tests live
in `lib/cron/__tests__/`.
